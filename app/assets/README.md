# 本地资源

- `fonts/NotoSansSC.ttf`：Google Fonts 的 Noto Sans SC 可变字体，SIL Open Font License，许可证见 `fonts/OFL.txt`。来源：https://github.com/google/fonts/tree/main/ofl/notosanssc 。
- `sample.webm`：本项目代码生成的 6 秒无声波纹短片，640×360、24 fps。它是展示视频采样的演示素材，不是 AI 生成结果。
- 可用本机 FFmpeg 和 `node scripts/generate-demo-video.mjs` 重新生成短片；正常启动应用不需要 FFmpeg。
