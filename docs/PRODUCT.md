# 流形 · Forma 产品与体验规格

状态：产品设计基线，尚未实现。本文中的尺寸、时间、密度、容量和阈值是首轮设计参数，不是设备性能实测。引擎架构以 [DESIGN.md](../DESIGN.md) 为准；协议和技术实现不得削弱本文的纯粒子显示条件。

## 1. 产品目标与边界

流形 · Forma 是可连接不同 AI 的独立回答面板。品牌文案为“让思想，自然成形”。用户可以阅读、操作和继续修改同一份回答；粒子既是表达材料，也是落板后的最终显示单元。

首版面向理解知识、比较数据、解释过程三类任务。核心闭环是输入问题 → 得到稳定可读的粒子回答 → 选中内容或调整参数 → 在原场景继续理解。成功不以动效数量衡量，而以用户能否读懂、选准、复制正确、继续追问和找回历史衡量。

回答区域内的正文、图形、图表、媒体、按钮、选区、焦点和提示全部由粒子绘制。已落板的文字持续作为粒子存在。面板外的导航、输入框、设置和全局运行状态采用普通控件；边界由布局固定，不能把回答内控件移出面板以规避约束。

首版范围包括文字、数据图、受限过程动画、图片、本地可控短片播放、对象追问、场景历史及两个不同模型提供方。视频素材生成、任意代码执行、多人编辑、插件市场、整窗粒子化和各聊天软件嵌入不属于首版。首版包含短片播放，不承诺通过一句话完成视频生成。

## 2. 页面与布局

桌面主界面由左侧会话导航、顶部工具栏、中央回答板和底部输入区组成。默认进入最近会话；首次启动进入空白会话，连接模型入口在顶部固定可见。没有凭据时允许打开本地示例，示例始终标明“本地示例”。

| 区域 | 初始规格 | 内容边界 |
| --- | --- | --- |
| 会话导航 | 240 CSS px，可折叠至 56 px | 会话、搜索、分支入口、设置 |
| 顶部工具栏 | 高 56 px | 名称、当前模型、连接状态、面板显示偏好 |
| 回答板 | 填充剩余空间，外边距 24 px | 所有回答与回答内交互 |
| 输入区 | 最小高 88 px，随文本增长至 180 px | 文本输入、发送、停止、附带的对象引用 |

回答板采用连续场景文档，可以垂直滚动。一次追问默认添加新回答段，原内容可回看；明确“修改这个”时才更新目标节点，并生成可回退的版本。正在阅读或选择时不强行滚到末尾；出现新内容后，在板内显示粒子绘制的“查看新内容”。

正文阅读宽度以 680 px 为上限，宽图表和媒体可扩至 1120 px；超宽数据提供缩放、平移或表格查看，不挤压正文到不可读。滚动可以使用外部原生滚动容器，场景坐标与命中同步；滚动条属于外壳设施，内容不能另建可见文字层。

窗口宽度 ≥1200 px 展开导航；768–1199 px 默认折叠；<768 px 使用单列和覆盖式导航，板边距 16 px，工具栏隐藏次要文字。窄屏正文仍为 16 px，图表重排标签或分段展示，不缩小整板。软键盘出现时输入区保持可见；拖动图表不劫持整页纵向滚动。

## 3. 从液态待机到稳定回答

空板中央是约 112 px 的液态粒子聚集体，缓慢呼吸，旁有简短粒子提示“让问题在这里成形”。液态区域体现板的可塑性，不虚构进度百分比；已存在回答时不在正文上方持续覆盖一个装饰球。

发送后，输入内容进入请求记录，板内显示真实状态：等待模型、接收内容、组织画面或等待素材。纯文本可以按完整字符分批落板；图表等结构化回答在完整草稿校验通过后整体提交，不显示半截结构。默认动效让局部粒子在约 180–420 ms 内到达内容位置；大篇幅回答优先稳定首屏，其余按块形成。这个时间范围是动效设计值，不是网络响应承诺。

粒子到位后保持稳定，不闪动、不微漂移、不淡出成另一种文字。补充内容只改变相关区域。文字已成为用户阅读对象后，装饰性运动不能反复打散它。结束状态使用短暂的板内提示后收起，不让整板再次聚散。

“停止”终止当前生成，并保留最后有效内容，标记“已停止，内容未完整生成”。未提交的半截结构不进入画面。减少运动模式直接更新粒子状态，保留必要进度与反馈；静态显示仍然全部是粒子。

## 4. 输入、选择和继续对话

输入框支持多行；Enter 发送，Shift+Enter 换行，输入法组合期间 Enter 只确认候选。发送按钮旁明确显示下一次请求的提供方和模型。模型不可用时保留草稿，连接操作不会自动发送。

板内统一使用对象选择与文本选择：点击图表、图片或形状选择对象；在文字中拖动建立文本范围；空白处点击清除选择。触屏通过长按进入选择，并提供可拖动端点。目标命中范围最小 44 × 44 px，相邻小标记用最近语义对象和明确反馈区分。

选择后出现粒子操作条，默认提供“追问”“复制”“查看来源”；图表另有“查看数据”，媒体另有播放操作。操作条不得覆盖正在选择的文字。追问时输入区显示引用摘要及可移除的引用标签；发出的上下文包含当前已显示版本、对象标识和必要数据切片。用户可在发送前看出引用了什么。

复制文字取真实 Unicode 文本，不对画面做识别；复制数据保留单位、空值与行列关系。复制动作由用户触发，并给出短暂成功反馈。来源缺失时写明“未提供来源”，不展示可点击的虚构引用。外链明确显示目标域名，点击后打开外部页面。

用户正选字、拖动或调整播放时，相关对象的竞争更新暂存。首版可以延后整笔更新；操作完成后提交，超时则撤销候选并保留原画面，提示重新生成。禁止选区停在旧位置而复制新文本。

## 5. 数据、动画与媒体交互

图表初始显示标题、单位、图例及数据来源状态。悬浮或键盘聚焦数据点显示粒子数值提示；触屏第一次点击查看数值，明确的追问按钮才发起模型请求。图表切换形式、查看原始数据、缩放和已知参数调整在本地完成，不产生模型调用。

“查看数据”在板内展开粒子表格，支持按行导航与复制；大数据分页或虚拟滚动。零、负数、缺失值和估算值分别表达，不让缺失值默认为零。重新计算结果时，图形、数值和可点击范围同时生效。

过程动画首版提供开始、暂停、重置与固定播放速率档位，这些属于本地视图控制。模型自定义的科学参数绑定与可持久保存的参数编辑后置。演示可以标明“示意，比例已简化”。暂停应冻结相关时间线；解释文字保持可读。没有可计算的关系时，不提供看似精确的参数模拟。

视频默认静音，不自动播放带声音的素材。画面、字幕、播放按钮、进度条、时间标签和错误提示均位于板内且由粒子显示。点击播放才启动，拖动进度后先显示目标时间的可用帧；旧位置迟到的帧不能反向跳回。视频不可解码时保留说明及重试入口，不覆盖普通播放器。

本地短片仅在当前会话授权范围内读取。后续接入生成媒体时，必须单独显示服务、预计消耗和任务状态；渲染故障不能重复触发收费任务。首版默认关闭生成媒体入口。

## 6. 历史、分支与模型切换

会话包含有序回答与场景版本。历史入口显示用户问题、回答摘要、使用模型及完成状态，不使用纯截图作为唯一记录。返回历史后重新形成相同语义内容；字体或设备变化造成的像素差异可以存在。

回看历史版本为只读；从旧回答继续追问必须建立分支，原路径保留，分支入口同时显示来源问题。当前分支的修改可以撤回，撤回产生一份恢复前态的新版本，既有历史不删除。撤回不宣称撤销已经发送的请求或外部任务。

切换模型只影响下一次请求，不重跑旧回答。第一次将会话发送给新的提供方时，在发送动作中清楚展示提供方和上下文范围；默认发送必要历史摘要、引用对象和用户此次输入，不上传完整媒体文件或全部会话。范围可检查与调整，且按连接保存偏好。

本地保存草稿、语义场景、版本关系和资产引用。设置中可以导出场景包或删除会话。删除时列出本地范围，不能暗示同步删除模型提供方已保存的数据。敏感凭据不进入场景导出、调试截图或历史正文。

## 7. 空态、错误与恢复

| 状态 | 用户看到什么 | 可采取的动作 |
| --- | --- | --- |
| 没有模型连接 | 液态空板；外壳提示“连接模型或打开示例” | 配置连接、使用示例 |
| 等待与流式生成 | 真实阶段状态；逐块形成有效内容 | 停止、继续阅读已有内容 |
| 结构无法采用 | 保留有效场景；可用正文以粒子文字显示 | 重试、查看已获得的内容 |
| 网络中断 | 标记中断，保留草稿和已落板内容 | 手动重试；重试是新请求 |
| 额度或鉴权错误 | 显示提供方返回的可理解原因 | 修复连接、换模型 |
| 资产失败 | 对应区域显示粒子占位与原因 | 重试资产、移除该项 |
| 渲染器恢复中 | 外壳显示恢复状态，保留场景数据 | 等待重建、导出场景 |
| 没有合规显示后端 | 外壳说明兼容性限制，板停止显示 | 导出数据、选择支持环境 |

仅外网离线时，本地网关可继续保存本地修改；网关也不可达时，只能查看浏览器缓存、复制和进行播放等视图操作，内容修改保持为草稿，等待版本同步。恢复网络不自动发送草稿，不重复请求媒体。事件连接可以恢复订阅同一请求；只有明确重试生成才创建新请求。

## 8. 视觉与可访问性

默认采用温暖浅色板，液态区域使用低饱和蓝紫色。正文、图表和控件的颜色来自语义角色，模型只能请求角色，不能任意生成影响可读性的样式。以下为初始 tokens，实施时测量对比度并校正。

| Token | 初值 |
| --- | --- |
| shell / board | `#F3F1EC` / `#FCFBF8` |
| text.primary / secondary | `#202623` / `#545F58` |
| accent / focus | `#405AD6` / `#244DC7` |
| selection / border | `#DDE6FF` / `#CBD2CC` |
| success / warning / error | `#256442` / `#805000` / `#B12B3C` |
| 标题 / 正文 / 辅助文字 | 28/36、16/26、14/22 px，字号/行高 |
| 间距 / 圆角 | 4、8、12、16、24、32 px / 8、16、24 px |

回答字体首轮锁定一个合法授权的中文无衬线字体包，记录实际版本，系统字体只用于外壳或明确登记的回退；数字默认等宽数字。深色主题留作后续完整对比度验收，首版不使用简单反色。正常文字对比度目标至少 4.5:1，交互边界和焦点目标至少 3:1；状态同时有文字或形状，不只靠颜色区分。

颗粒风格提供“清晰”“颗粒”两档，默认清晰。清晰模式让微粒相接，保证细笔画；颗粒模式提示细节变化，并可随时恢复。质量设置与表现风格独立；性能降低不能未经用户选择把正文变成明显散点。

键盘 Tab 按阅读顺序进入动作，Enter/Space 激活，Escape 关闭当前板内浮层或退出选择。播放控件获得焦点后 Space 才切换播放，避免抢占输入操作。焦点环由粒子绘制。放大至 200% 时内容重排，关键动作保持可达。

不可见语义树提供标题层级、真实文本、图表摘要、数据表和媒体名称；操作与画面来自同一场景版本。流式回答按完整语义块播报，避免逐粒子或逐字刷屏。尊重系统减少运动偏好，并提供常驻开关。辅助技术和输入法需在真实平台验收，不能以截图或 DOM 检查代替。

## 9. 产品验收

首版发布前必须完成六个连续任务：无凭据打开示例；连接模型获得中文回答；选择一句话追问并复制；查看图表数据并切换表达；播放和拖动本地短片；在另一模型上继续一个历史分支。每项记录成功路径、异常路径和恢复结果。

硬门槛包括：停用粒子绘制并清除缓存后板内全部内容消失；小字号中文和混合字符可读；滚动、换行与缩放后选择准确；文本复制与语义源一致；视频字幕及控件无旁路；旧请求不能覆盖新版本；键盘及读屏可完成核心操作；减少运动不改变内容与交互能力。

首轮可用性研究邀请 5–8 名目标用户执行上述任务，记录完成率、误操作、需要解释的位置和主观负担，用于发现问题，不把小样本当统计证明。性能另附设备、窗口、绘制倍率、内容规模及持续运行记录。未通过纯粒子显示和可读性门槛前，不用新动效或更多模型数量抵消问题。
