# 流形 · Forma 1.0

让思想，自然成形。一个可连接不同 AI 的本地粒子回答面板。

**粒子落板就是最终画面。** 文字、图表、动画、图片和视频帧都由 WebGL2 粒子显示，落板后不会交给 DOM、SVG 或可见视频元素。内容编译器内部包含必要的排版、粒子绘制和交互运行代码，没有另开通用引擎项目。

当前版本可本地运行；模型适配器已用本机假上游验证请求格式、取消和错误处理，**尚未使用真实 API Key 完成在线联调**。无模型配置时是预设和规则示例，不会假装生成 AI 回答。

待机时，空白板中央是一团黑色液体。内容到来后，同一批材料沿非线性路径移动并在途中渐变颜色，接近目标时形成清晰格点。默认展开时间尺度约 2.6 秒；到位后继续读取同一材料状态，不在终点换图。

本次修正贯穿整体显示架构：通用 `MaterialPlan` 编译目标与归属，`MaterialState` 保留材料的位置、速度、颜料和附着状态，唯一 WebGL2 管线负责液面与内容格点。已移除独立中央黑团、补画液桥和终点绕过材料的分支。文字、图表、图片、动画与视频共用该机制；视频换帧、节点运动及滚动保留材料归属。

材料预算与显示格点预算分开：有限数量的带权材料驱动像素级显示，窗口变化不会重新创建正在使用的材料池。当前采用固定步弹簧与邻域速度耦合，不是完整物理流体求解器。架构约束、模块边界和限制见 [DESIGN.md](DESIGN.md)。

真实运行录屏见 [统一材料展开](artifacts/material-flow-space-pi.mp4)。启动后访问 `/qa/liquid.html` 可检查中间状态、材料数量和实际画布录像；这里与主面板共用编译器。`/qa/index.html` 检查材料连续性、驻留状态、媒体更新和最终像素。

## 启动

需要 **Node.js 22 或以上**，以及支持 WebGL2 的浏览器。项目没有 npm 依赖，无须执行 `npm install`。

在项目目录运行：

```sh
npm start
```

然后打开 [http://127.0.0.1:4173](http://127.0.0.1:4173)。也可直接运行 `node server.mjs`。

macOS 可双击 [启动流形.command](启动流形.command)。启动器检查 Node 版本和同端口服务：只有健康接口确认是 Forma 1.0 时才复用；其他进程占用时退出，不会杀掉其他服务。新启动成功后自动打开浏览器，在启动终端按 **Ctrl+C** 停止服务；复用实例需在原启动终端停止。

需要更换端口时：

```sh
FORMAPORT=4174 npm start
```

服务只监听 `127.0.0.1`。不要直接打开 `app/index.html`，模块和 API 需要通过上述本地 HTTP 服务加载。

## 先试什么

1. 左侧打开「文字落板」「数据有形」「轨道与运动」「逐帧短片」。示例数据和动画均明确标注为演示。
2. 切换「清晰／颗粒」，开启「扰动」，观察已落板内容仍由粒子组成。
3. 拖选文字，或点击柱体与数据点，然后复制、引用追问。图表可切换柱状／折线，并查看与复制数据。
4. 用输入区的「＋」添加本地图片或视频，文件只在当前页面会话中读取，不发送给模型。
5. 需要自由提问时，在右上角「连接模型」填写接口、API 根地址、模型 ID 和 Key。

## 连接模型

| 接口类型 | API 根地址示例 | 网关使用的路径 |
| --- | --- | --- |
| OpenAI 兼容接口 | `https://api.openai.com/v1` | `/chat/completions` |
| Anthropic Messages | `https://api.anthropic.com/v1` | `/messages` |
| 本机兼容模型 | `http://127.0.0.1:端口/v1` | 依选择的接口类型追加 |

模型 ID 必须由所用服务商实际支持。API Key 只保存在本机服务进程内存中，不写入磁盘或浏览器历史；重启服务或断开连接后需要重新填写。远程地址要求 HTTPS，本机地址允许 HTTP 和空 Key。保存设置只校验格式，首次发送才会请求提供方。

**已连接模型时，提问、当前面板文字和选中引用会发送给配置的服务商。** 本地媒体文件本身不会随提问上传。停止按钮会取消请求；本地网关最长等待 60 秒。

## 本版范围

- 已有：纯粒子显示、中文字形、选择复制、柱状／折线图、受限动画、浏览器可解码的本地媒体、JSON 场景导入导出、最近面板、两类模型适配器。
- 历史：浏览器 `localStorage` 最多保留 20 条场景快照；不是 SQLite 数据库，也没有完整分支、同步或资产归档。
- 媒体：仅当前页面会话可用。刷新后需要重新导入，场景 JSON 不打包媒体；内置示例短片可再次加载。
- 协议：执行 `panel-scene/0.3` 的受限子集，以 [app/scene-validation.js](app/scene-validation.js) 为准。原始设计 Schema 中的全部能力并未实现。
- 未包含：自动接管其他聊天软件、视频／图片生成服务、插件市场、多端同步，以及 WebGPU 或 Canvas2D 渲染后端。

完整使用说明、当前限制和验证记录见 [docs/V1.md](docs/V1.md)。

## 检查

```sh
npm test
npm run check
```

自动测试 **45/45** 通过，真实浏览器 GPU 验收 **16/16** 通过。新增的核心检查包括：移走全部材料时液面归零；100% 后改变材料状态仍改变最终画面；视频透明区域更新、目标运动、滚动与缩放保留归属。最新结果见 [material-pipeline-qa.json](artifacts/material-pipeline-qa.json)。用 `/?qa=1` 可在内存隔离的测试面板中操作，不读写用户历史与偏好。

自动测试覆盖协议与场景、布局计算、本地场景路由和服务边界。服务测试只调用本机假上游，不消耗模型 API 额度。浏览器画面、粒子可寻址性和交互验收另见 [1.0 验证记录](docs/V1.md#验证记录)，自动测试不代表已完成跨设备性能验证。
